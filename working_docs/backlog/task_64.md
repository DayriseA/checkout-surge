## Implementation record

- **Status:** Implemented and focused verification complete.
- **Completed scope:** Added the Next.js byte-stream route, made the browser URL invariant, removed the public override, isolated exact-path Caddy streaming from gzip with lifecycle-safe automatic SSE flushing, and updated focused tests and current documentation.
- **Decisions:** Successful upstream bodies are passed by identity with fixed SSE headers. Upstream non-success responses preserve only their status; bodies and headers are not exposed. Transport failures and successful responses without a body return an empty `502`. The proxy forwards only `Accept`, `no-store`, and the incoming abort signal. Caddy relies on its automatic immediate flushing for `Content-Type: text/event-stream` and keeps the request's default upstream cancellation behavior.
- **Deviations:** Both Caddyfiles intentionally omit the prescribed `flush_interval -1`. Caddy documents that SSE responses already flush immediately and that negative flush mode does not cancel the backend request after an early client disconnect. Omitting it preserves API fan-out connection and heartbeat reclamation without sacrificing incremental SSE delivery.
- **Verification:** Focused web tests passed (`4` files, `12` tests), including the route, URL invariant, native EventSource behavior, and both Caddy configurations. Existing API SSE tests passed (`2` files, `21` tests). `pnpm --filter web type-check`, `pnpm --filter web lint`, and `docker compose config --quiet` passed; Compose emitted only the expected warning that `ADMIN_EDGE_ATTESTATION_SECRET` was unset. The final repository search found no public override references outside the intentional invariance test.

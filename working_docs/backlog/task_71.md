The event helpers map destination states to the corresponding `reservation.*` or `order.*` event name. These helpers are contract policy, not database mutation helpers, and the event helpers accept only the destination (including initial `secured`, `rejected`, and `queued` states), so do not infer that they validate a `(from, to)` pair.
